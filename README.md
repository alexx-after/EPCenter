# EPCenter

EPCenter — Windows-приложение для инвентаризации сертификатов электронной подписи.

## Текущий этап: 0.2
Реализовано чтение Windows Certificate Stores: CurrentUser\\My и LocalMachine\\My. Для сертификатов с привязанным закрытым ключом выполняется тихая проверка возможности получить дескриптор ключа через Windows CryptoAPI/CNG.

Проверка использует silent-режим: EPCenter не вызывает диалог PIN, не выполняет подпись и не экспортирует ключ. Если провайдер требует интерактивного подтверждения, это отображается отдельным статусом. Результат проверки доступности не означает, что ключ экспортируем.

## Требования
- Windows 10/11 или Windows Server 2019/2022/2025
- .NET 10 SDK

## Сборка
```powershell
dotnet restore EPCenter.sln
dotnet build EPCenter.sln -c Release
dotnet run --project src/EPCenter.App/EPCenter.App.csproj
```

## Структура
- EPCenter.Core — модели и контракты.
- EPCenter.Infrastructure — чтение хранилищ и проверка закрытых ключей.
- EPCenter.App — WPF-интерфейс.

## План развития
1. Проверка доступности закрытого ключа без экспорта — реализована базовая тихая проверка.
2. Интеграция с CryptoPro CSP и перечисление контейнеров.
3. Обнаружение Рутокен, JaCarta и других устройств через системные криптопровайдеры.
4. Поиск файловых контейнеров на съёмных носителях.
5. Отдельный модуль экспорта PFX с проверкой результата и индивидуальным паролем.

Неэкспортируемые аппаратные ключи не обходятся. PIN вводится только через штатный интерфейс криптопровайдера.
