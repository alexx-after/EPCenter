# EPCenter

EPCenter — Windows-приложение для инвентаризации сертификатов электронной подписи.

## Версия

Текущая версия: **0.8.0**.

Используется семантическая схема версий **MAJOR.MINOR.PATCH**:
- **MAJOR** — несовместимые изменения архитектуры или форматов.
- **MINOR** — новая функциональность с сохранением совместимости.
- **PATCH** — исправления ошибок и небольшие улучшения.

Единый номер версии задаётся свойством `Version` в `src/EPCenter.App/EPCenter.App.csproj`. Из него формируются отображаемая версия приложения, AssemblyVersion и FileVersion. При выпуске следующей версии обновляйте `Version`, `AssemblyVersion` и `FileVersion` согласованно.

## Текущий этап: 0.8
- Чтение Windows Certificate Stores: CurrentUser\\My и LocalMachine\\My.
- Тихая проверка доступности закрытого ключа через Windows CryptoAPI/CNG. PIN не запрашивается, подпись и экспорт не выполняются.
- Обнаружение установленного CryptoPro CSP и отображение версии в главном окне.
- Перечисление контейнеров CryptoPro через штатную утилиту `csptest.exe` отдельно для области пользователя и компьютера.
- Чтение `CERT_KEY_PROV_INFO_PROP_ID` у сертификатов: имя контейнера, имя провайдера, тип провайдера и флаг машинного хранилища.
- Сопоставление сертификатов с перечисленными контейнерами по имени и области хранения. Результат отображается в таблице сертификатов.
- Для перечисления используется режим проверки контекста; содержимое контейнеров не читается и не изменяется.
- Перечисление PC/SC считывателей через Windows Smart Card Resource Manager (winscard.dll).
- Отображение системного имени считывателя и осторожной подсказки о производителе по имени устройства. Это не является аппаратной идентификацией токена.
- Подключение к карте через PC/SC в режиме shared и чтение ATR через SCardStatus.
- Отображение состояния карты: карта не вставлена, обнаружена, считыватель занят или ошибка PC/SC.
- ATR отображается в HEX. По ATR модель пока автоматически не определяется: для этого потребуется проверенная база ATR-профилей.
- После проверки выполняется SCardDisconnect с SCARD_LEAVE_CARD; PIN, APDU-команды, подпись и операции с закрытым ключом не используются.
- Поиск файловых контейнеров CryptoPro на локальных фиксированных, съёмных и подключённых сетевых дисках (DriveType.Fixed, DriveType.Removable и DriveType.Network).
- Контейнер распознаётся по наличию шести имён файлов: header.key, masks.key, masks2.key, name.key, primary.key и primary2.key.
- Поиск ограничен глубиной 12 каталогов и 100 000 каталогов суммарно за запуск; системные каталоги и reparse points пропускаются. Для снижения лишнего обхода исключены стандартные системные каталоги Windows, Program Files, ProgramData и Recovery. Сетевые диски также сканируются; фактический доступ зависит от прав текущего пользователя и наличия подключения.
- Проверяются только имена файлов и структура каталогов. Содержимое ключевых файлов не открывается и не копируется.
- При поиске файловых контейнеров приложение дополнительно сканирует хранилища сертификатов Windows CurrentUser\\My и LocalMachine\\My.
- Для предварительного сопоставления используются имя провайдера CryptoPro и точное совпадение последнего компонента имени контейнера с именем папки.
- При единственном совпадении в таблице отображаются имя владельца (SimpleName сертификата), срок действия с/по и отпечаток сертификата.
- При отсутствии или неоднозначности совпадения владелец и даты не подставляются; статус явно показывает результат.
- Сопоставление по имени является эвристикой. Оно не доказывает, что найденная папка является используемым CSP контейнером, что закрытый ключ доступен или что он экспортируем. Для подтверждения потребуется отдельная проверка штатными средствами CryptoPro.

**Важно:** наличие контейнера не означает, что закрытый ключ доступен без PIN или что он экспортируем. Неэкспортируемые аппаратные ключи не обходятся.

## Требования
- Windows 10/11 или Windows Server 2019/2022/2025
- .NET 10 SDK
- CryptoPro CSP для обнаружения и перечисления его контейнеров

## Сборка
```powershell
dotnet restore EPCenter.sln
dotnet build EPCenter.sln -c Release
dotnet run --project src/EPCenter.App/EPCenter.App.csproj
```

## Структура
- EPCenter.Core — модели и контракты.
- EPCenter.Infrastructure — чтение хранилищ, проверка закрытых ключей, обнаружение CryptoPro и перечисление контейнеров.
- EPCenter.App — WPF-интерфейс.
